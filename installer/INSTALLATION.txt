Barhex - Windows installation

This installer installs Barhex for the current Windows user. Administrator
access is not required. The default location is:
  %LOCALAPPDATA%\Programs\HexShift

Launch Barhex from the Start menu or desktop shortcut. It runs in its own
window; the editor does not require a hosted website or an Internet connection.
Microsoft .NET Framework 4.8 and the Microsoft Edge WebView2 runtime are required.
If WebView2 is missing, the app offers to open Microsoft's runtime download page.

Barhex upgrades an installed copy of Hex Shift in place and uses the same
profile under %LOCALAPPDATA%\HexShift. Portable copies and saved sessions stay
where you put them. Export your image or save a session before closing Barhex.

Remove the installed app through Windows Settings > Apps > Barhex > Uninstall.
Uninstall removes the installed program and its shortcuts, but preserves exported
images, portable copies and the app's local data.

Barhex can check for updates and notify you when one is available. It
downloads and installs an update only after you agree. Save your work before
installing an update. Setup then asks "Barhex was updated. Open it now?".
Choose Yes to reopen it or No to leave it closed.
This installer and executable are unsigned; no publisher signing identity has
been provisioned.
