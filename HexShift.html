Shortcuts & file support

Ctrl/Cmd O opens an image. Ctrl/Cmd Z undoes; Ctrl/Cmd Shift Z redoes. Shift-click adds a sample. Escape clears the selection. Space-drag pans. + / − zoom; F fits. Native text-field shortcuts remain available.

Static SVG supports shapes, paths, text, gradients, clips, masks, blend modes and filter effects. Active content, external resources, reuse elements and embedded images are rejected. SVGs are drawn at 512 px on their longest side; change it under SVG drawn at. All exports are still images. Sizes for Discord, Slack, Twitch, Telegram, WhatsApp and YouTube fit and centre the artwork and show the file size against each limit. Preview backgrounds never change exported transparency. For a background, Clean edges works best with Only connected regions.
