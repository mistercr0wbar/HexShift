Shortcuts

Ctrl/Cmd O opens an image. Ctrl/Cmd Z undoes; Ctrl/Cmd Shift Z redoes. Shift-click adds a sample. Escape clears the selection. Space-drag pans. + / − zoom; F fits. On touch screens, pinch to zoom and drag with two fingers to pan.

Opens PNG, JPEG, WebP, GIF and static SVG up to 4 megapixels; animated files open as stills. Static SVG supports shapes, paths, text, gradients, clips, masks, blend modes, filter effects, reused shapes and the files Illustrator, Inkscape, Sketch and Figma export; active content, external resources and embedded images are rejected. SVGs are drawn at 512 px on their longest side; change it under SVG drawn at. Sizes for Discord, Slack, Twitch, Telegram, WhatsApp and YouTube fit and centre the artwork and show the file size against each limit. Preview backgrounds never change exported transparency. For a background, Clean edges works best with Only connected regions.
