Shortcuts & file support

Ctrl/Cmd O opens an image. Ctrl/Cmd Z undoes; Ctrl/Cmd Shift Z redoes. Shift-click adds a sample. Escape clears the selection. Space-drag pans. + / − zoom; F fits. Native text-field shortcuts remain available.

Static SVG supports shapes, paths, text, gradients, clips, and masks. Active content, external resources, filters, reuse elements, and embedded images are rejected. All exports are still images. Preview backgrounds never change exported transparency.
